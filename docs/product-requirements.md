# 製品要件と開発順序

更新: 2026-10-26。要件は確定・設計判断・未決を区別する。

## 確定した対象

- 初期対象は民間の修繕・改修。公共工事・新築は初期対象外。
- 設置先はConoHa VPS。今回、契約・課金・外部公開は行わない。
- スマートフォン以外の専用機器を要求しない。CCUS等の外部業務システム連携は保留。
- 便利なだけの機能を増やさず、受発注・施工・成果提出・支払・法令上の義務に必要な機能を優先する。
- メインメニューは簡潔にし、工事ごとに次に必要な作業を案内する。過去の記録は後から参照できる。
- 写真は工事画面から撮影して直ちに当該工事へ保存する。後日の手動アップロードを標準手順にしない。
- 工程表、写真台帳、業者が取得できる工事のお知らせを提供する。

## 保存先の役割

GitHubはコード・設計・変更履歴の保管先。業務データの保存先ではない。
VPSのPostgreSQLに工事・権限・記録を、非公開ファイル保管先に写真・証憑を置く。
製品のブラウザ保存は撮影直後の送信待ち・再送用に限定する。端末保存完了とサーバー保存完了を区別する。
本番データ・秘密情報・実案件の写真を公開リポジトリやGitHub Pagesに置かない。

製品用画面は工事基本情報・履歴、契約前確認と、その後の社内業務フローを提供する。実装と制限は [product-workflow-progress.md](product-workflow-progress.md) を参照。
P04は工事条件、施工範囲、金額と許可、関連条件の4段階で途中保存できる。不明と未入力を区別し、工事変更後は以前の前提との比較と明示的な再確認を求める。
許可証・資格・証拠資料の内容審査や、金額等による許可要否の自動判定は未実装。契約成立・着工許可・適法性を示すステータスは提供しない。
詳細な実装範囲と検証結果は [product-classification-progress.md](product-classification-progress.md) を参照。

## 入力と作業導線の要件

2026-10-24の利用者指摘を反映する。入力項目を並べるだけでなく、工事登録後の次の作業と、回答保存後の残りの作業を具体的な操作として提示する。
以下の入力導線は実装・検証済み。証憑は担当者が内容を照合し、根拠と結論を記録する。自動審査は行わない。

- 未回答は内部状態として保持し、利用者に「未入力」を選ばせない。確認できない回答は「後で確認する」として残し、回答済みと同一視しない。
- 金額・工事候補を直接入力・選択する。回答状態の選択を入力の前提にしない。
- 支給材・分割契約・下請発注の有無から、今必要な従属項目だけを表示する。既存回答と新しい親回答が矛盾する場合は、変更対象を明示して確認し、無断で既存値を削除しない。
- 新しい金額は税込の入力欄として明示できる。過去の税抜・税区分不明はそのまま保持し、表示の簡略化を理由に金額の意味を変えない。
- 入力の省略と法的な適用除外を区別する。請負額だけで許可・資格・届出の確認課題を消さない。
- 保存成功後だけ次の段階へ進める。未実装の資料審査や契約を、完了表示や動作しないボタンで代用しない。

## 権限の初期範囲

初期実装は会社の内部担当者のみ。管理者・担当者は工事を更新でき、閲覧者は読取のみ。
外部協力業者への全社情報開示はしない。工事単位招待、写真担当者の範囲、書類の公開先は次段階で設計・試験する。
利用者自身による役割切替・会社ID指定だけでのアクセス許可は禁止。
公開の新規登録は提供せず、運営者がCLIで初回アカウントを発行する。本人確認・招待・再設定・MFAの整備後に実運用する。

## 法令の扱い

「全法令の遵守を自動保証」とは表示しない。適用条件・根拠・施行日・証拠・承認者を管理し、未確認事項を隠さない。
民間修繕でも建設業法以外の電気工事、建設リサイクル、石綿、廃棄物、安全衛生等が条件により関係する。
外部連携の除外は、法定届出や資格確認、安全措置を不要にすることではない。
契約書の共通事項と工事種類による追加要件を分け、29種類のメニューや一律の契約テンプレートで代用しない。
既存の法令調査・不足一覧は [compliance-review-2026-10-22.md](compliance-review-2026-10-22.md) に継続記録する。
法令担当者によるレビューと運用責任者の承認を公開前の条件とする。

## 未決事項

- 利用会社数・利用者数・月間工事件数・写真容量・保存年数。保存年数は文書種別と義務を確認して決める。
- ドメイン、VPSのOS・容量・監視、メール送信、管理者、サポート窓口。
- バックアップの許容損失時間と復旧時間、別拠点保管先、費用上限。
- 契約締結方式、証憑の確定・訂正・保管、役割別の承認者、個人情報の取扱規程。

未決事項を暗黙の本番設定にせず、各段階の着手・公開判断で解消する。
